# Raw data sources and licences

The files in this directory are normalised extracts of the public sources listed below (model, date, score or count),
kept so that the site data can be rebuilt offline (recomputation) without refetching. They are not copies of the upstream
files. Each source stays under its own licence and terms; the credit line is what the site shows for it.

This file is generated by `npm run fetch` from the `meta` of every module in `src/sources` (see `src/raw/licenses.ts`); do not edit it by hand.

## Sources without an explicit data licence

Their data is published openly but states no data licence of its own (or the terms are unclear); it is cited and credited, not relicensed.

- `vbench` (VBench): No explicit data licence (leaderboard Space: MIT, VBench code: Apache-2.0)
- `tts-arena` (TTS Arena): No explicit data licence (leaderboard published openly; code: Apache-2.0)
- `tranco` (Tranco top sites list (with subdomains)): No licence of its own; cite Le Pochat et al., NDSS 2019 (non-commercial use; includes Cloudflare Radar data, CC BY-NC 4.0)
- `itunes` (Apple App Store rating counts (US, iTunes Lookup API)): Public API, rating counts only (terms unclear; no artwork)
